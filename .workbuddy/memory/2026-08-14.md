## 英文版下面板节点过滤

按用户需求"英文版状态下节点只显示 Seedream 和 seedance 模型和免费模型"实施：

**新增工具文件**：`frontend/src/config/internationalEditionNodes.ts`

- `isSeedreamPaletteConfig`：识别 Seedream 系列（节点 key、serviceType、metadata.model / flowNodeType / provider / nodeKey 包含 seedream）
- `isSeedancePaletteConfig`：识别 seedance 系列（doubaoVideo / seedance20Video / serviceType=doubao-video / model 含 seedance / provider 含 seedance）
- `isFreePaletteConfig`：识别免费节点（`creditsPerCall === 0` 且没有 serviceType / 没有 priceYuan）
- `isAllowedForInternationalEdition`：国际版白名单合并入口
- `isInternationalLanguage`：locale → 国际版判定（en → 国际版，其它 → 国内版）

**修改 FlowOverlay.tsx**：
- 导入新工具
- 从 `useLocaleText()` 解构 `language`
- `nodePaletteConfigs` useMemo 中追加一道过滤：国际版下不在白名单的节点隐藏
- useMemo 依赖加上 `language`，切换语言时面板自动重排

**国际版白名单覆盖范围**：
- Seedream 5.0 / 5.0 Pro（doubao-seedream-5-0-260128、doubao-seedream-5-0-pro-260628）
- Seedance 1.5 Pro / 2.0（doubaoVideo、seedance20Video）
- 0 积分的本地工具节点：textPrompt / textNote / image / video / camera / audioUpload / videoFrameExtract / videoCompose / storyboardSplit / imageGrid / imageSplit / imageCompress / textPromptPro / imagePro

**国际版隐藏**：所有其它付费节点（generate / generate4 / midjourney / nano2 / gptImage2 / wan26 / kling / vidu / sora2 / happyhorse / omniFlash / minimaxSpeech / minimaxMusic / tencentSpeech / videoToGif 等）。`DOMESTIC_ONLY_SERVICE_TYPES` 服务端拦截逻辑仍生效，用户即便通过快捷连接拿到 minimax-speech，运行时会返回 `available: false`。

**保留兼容**：现有 `shouldHideForeignFlowNode`（受 `VITE_SHOW_FOREIGN_NODES` 控制）行为不变；本次新增的过滤仅基于 i18n.language，叠加在它之后。

## 系统默认语言开关（管理员可控）

按用户需求"加一个开关控制优先显示中文还是英文版"实施。

**复用现有基础设施**：`backend/src/admin/systemSetting` 表 + `upsertSetting(key, value)` + `SettingsPublicController`（无需鉴权）

**改动**：
- `backend/src/admin/settings-public.controller.ts` — 新增 `GET /api/settings/default-language` 公开端点，读取 `default_language` 设置项，规范化返回 `"zh-CN"` 或 `"en-US"`（默认 zh-CN）
- `frontend/src/services/adminApi.ts` — 新增 `fetchDefaultLanguage()` 公开拉取 helper
- `frontend/src/i18n/index.ts` — 新增 `applyServerDefaultLanguage()`：检查 localStorage 中是否有用户偏好（`tanva-locale`），**仅当没有时才应用服务端默认语言**
- `frontend/src/main.tsx` — `initializeRuntimeStability()` 后调用 `void applyServerDefaultLanguage()`（异步，不阻塞渲染）
- `frontend/src/pages/Admin.tsx` `SettingsTab()`：
  - 新增 `defaultLanguage` + `savingDefaultLanguage` state
  - `loadSettings()` 内拉取 `default_language` 项
  - 新增 `saveDefaultLanguage(next)` 调用 `upsertSetting`
  - 新增"系统默认语言"卡片 UI（中文/English 双按钮互斥样式 + 实时状态显示）

**优先级（由低到高）**：
1. 浏览器 navigator
2. 后端默认语言（管理员在 Admin 设置）
3. 用户 localStorage 偏好（用户主动切换）
4. i18next fallback (`zh-CN`)
